### 3-4. 説明文

```
kurofukubo（黒福簿）は、口座のお金を目的別に分けて管理できる、複式簿記の家計簿です。

■ 口座のお金を、目的ごとに
普通預金の残高を「生活費 30万円・旅行 20万円・積立 40万円」のように、目的別のタグに配分できます。
記帳すると、支出の内訳（食費・日用品など）と目的別の残高が同時に更新されます。
口座を分けなくても、使っていいお金と取っておくお金が分かります。

■ 純資産が見える
現金・預金・クレジットカード・投資・借入をひとつの帳簿でつなぐので、
「手元にいくらあるか」ではなく「差し引きでいくら持っているか」が分かります。
月ごとの推移をグラフで追えます。

■ 貸借対照表・損益計算書まで自動で
裏側は複式簿記です。記帳するだけで、貸借対照表・損益計算書・キャッシュフロー計算書ができあがります。
簿記の知識は要りません。

■ カードの締めと引き落としに強い
利用日と引き落とし日がずれても帳簿が合います。締め日・支払日を登録すれば、
未払い残高と引き落とし予定を自動で計算します。

■ 銀行連携なし・登録なしで試せる
銀行やカード会社のログイン情報は預かりません。
アカウントを作らなくても全機能を使え、データは端末内に保存されます。
アカウントを作ると、ウェブ版や別の端末と同じ帳簿を使えます。

■ 暗号化してから預けられる
パスフレーズを設定すると、端末内で暗号化してからサーバーへ送ります。
鍵は端末から出ないため、運営者も中身を読めません。

■ 主な機能
・目的別のタグ配分、予算
・貸借対照表、損益計算書、キャッシュフロー計算書
・クレジットカードの締め日・引き落とし日の管理
・プリセット、自動仕訳ルール、定期取引、一行入力
・レシートの読み取り（端末内で処理）
・実査・評価替え
・CSV の入出力（他の家計簿アプリの CSV からの移行に対応）
・記帳のリマインダー（端末内の通知）、アプリのロック

■ 料金
現在は全機能を無料で使えます。広告が表示されます。

■ ご注意
本アプリは記帳と集計を行うもので、税務・投資の助言は行いません。
```

一行入力は機能一覧の1項目だけ（リード・見出しには置かない）。
