# 黒福簿（kurofukubo）現行仕様

最終整理: 2026-06-14（本番反映済みの状態）。
インフラの具体値（バケット名・Distribution ID 等）は `NEXT_STEPS.md` の「環境メモ」を参照。

---

## 1. 概要

- **一言**: 複式簿記ベースの個人向け家計簿 SaaS。収支だけでなく **資産・負債・純資産（ストック）** を正しく把握できる。
- **公開URL**: アプリ `https://app.kurofukubo.com` ／ LP `https://kurofukubo.com`
- **対象**: 「今いくら持っていて、いくら借りているか」を正確に管理したい個人。クレカの利用と引落の時間差も追える。
- **コンセプト**: 複式簿記の正確さ × 家計簿アプリの手軽さ。登録なしで試せる。

---

## 2. 技術スタック / アーキテクチャ

| レイヤ | 採用 |
|---|---|
| フロント | React 18 + Vite（SPA）。状態は Context（Auth / Data / UI） |
| 配信 | CloudFront + プライベートS3（OAC） |
| API | API Gateway（REST）+ Lambda（Node20 / arm64） |
| DB | DynamoDB シングルテーブル（PK=`USER#<sub>`, SK=`JOURNAL#…`/`ACCOUNT#…` 等） |
| 認証 | Cognito（SRP + Google OAuth/PKCE） |
| IaC | AWS SAM（backend）／ホスティングは別テンプレート |

- **計算はクライアント完結**：残高・BS/PL/CF・クレカサイクル等は全てブラウザで算出。API は永続化に専念。
- **データ保存の二系統**：ログイン時は API→DynamoDB、ゲスト/Cognito未設定時は localStorage に自動フォールバック（`DataContext` が切替）。

### localStorage 主キー
`kk4_guest`（ゲストの全データ）／`kk_guest`（ゲストモードフラグ）／`kk_theme`（light/dark）／`kk_onboarded`（初回ガイド表示済み）／`kk_nav_hidden`（非表示画面）／`kk_guest_promo`（登録促進モーダル表示済み）ほかUI状態フラグ。

## 3. 認証・アカウント・課金

- **サインイン**: メール（Cognito SRP）／ Google ログイン。パスワード忘れ→再設定対応。
- **ゲストモード**: 「ゲストとして試す」で登録なしに全機能を利用（`localStorage` のみ・API不送信）。登録時に既存 `/api/import` でDynamoDBへ自動移行。
- **アカウント削除**: 設定のデンジャーゾーンから（Cognito AdminDeleteUser）。
- **ティア**: `guest | free | pro | family`（`config/tiers.js`）。**課金未実装のため実ログインは全員 `free`**。
  - ゲスト上限: タグ/口座/追加科目 各5件（`GUEST_LIMITS`）。登録で解除。

## 4. データモデル

| エンティティ | 主フィールド |
|---|---|
| accounts（勘定科目） | `id, code, name, type(asset/liability/equity/income/expense), sys`。負債はCC設定可（下記） |
| journals（仕訳） | `id, date(YYYY-MM-DD), desc, lines[]` |
| lines（明細行） | `accountId, side(dr/cr), amount, taxRate(0/8/10), splits[]?` |
| splits（タグ配分） | `tagId, amount` |
| tags（タグ） | `id, name, color` |
| wallets（口座/財布） | `id, name, accountId, defaultTagName?` |
| budgets（予算） | `accountId, amount`（月次） |
| presets（プリセット） | `id, walletId, type(in/out), name, desc, lines[]` |
| recurring（定期取引） | `id, name, frequency, day, nextDate, lines[]` |
| rules（自動分類） | `id, keyword, drAccountId, crAccountId` |
| allocs（タグ別配分目標） | `accountId, tagId, amount` |

- **勘定科目区分**: 資産 / 負債 / 純資産 / 収益 / 費用（デフォルト科目を初期投入）。消費税率は 0 / 8 / 10%。
- **CC設定（負債科目）**: `ccClose`（締め日）, `ccDay`（引落日）, `ccDelay`（1=翌月/2=翌々月）, `ccFrom`（引落口座=資産）。

### 残高の定義（複式簿記の核）
- 資産・費用 = **借方残高**（dr − cr）
- 負債・純資産・収益 = **貸方残高**（cr − dr）
- BS/PL/CF はこの定義から仕訳のみで自動導出（CFは簡易直接法：現金科目の増減を相手科目区分で営業/投資/財務に3分類）。

## 5. 画面構成（サイドバー）

ユーザーは設定で各画面を表示/非表示にできる（`core` 画面=ダッシュボード/仕訳入力/設定 は常時表示）。

### メイン
- **ダッシュボード**: KPI（総資産/負債/純資産/収入/支出/収支）、円グラフ（資産構成/収入内訳/支出内訳）、今月の予算バー、月次推移（直近6ヶ月・棒）、初回セットアップチェックリスト。
- **仕訳入力**:
  - クイック入力（「食費 1200 現金」の1行記帳）、プリセットから記帳（チップ）、CSV取込、＋新規仕訳。
  - 一覧：**日付/摘要/借方/貸方/借方金額/貸方金額 をソート可**。摘要・科目で検索。期間指定。
  - **一括選択モード**（「☑ 一括選択」トグル）：ONでチェックボックス表示＋行クリックで選択。**一括削除**／**一括編集**（日付・摘要・借方科目・貸方科目をまとめて変更、金額は不変）。
  - 仕訳モーダル：借方/貸方の複数行、税率、タグ配分（split）。**ポイント利用**欄（下記）。多重送信ガード。
- **クレジット**: CC設定済みカードごとに1枠で表示。
  - ヘッダ（未払残高・次回引落）＋ **グラフ2種**（サイクル別利用額の棒／科目別利用内訳のドーナツ）＋ サイクル表。
  - サイクル表：締め期間・件数・利用額・引落予定日・状態（締め前/未引落/引落済/利用なし）。行タップで利用明細を展開。
  - **期間指定＝引落日が期間内**のサイクルを表示（今月＝今月引落分 等）。
- **仕訳帳**: 期間別の総勘定元帳。CSV/PDFエクスポート。
- **カレンダー**: 月カレンダーに日別の収入/支出/件数。日選択でその日の仕訳一覧→**編集/削除可**。

### レポート（各画面 CSV/PDF エクスポート、用語ツールチップ付き）
- **貸借対照表（BS）** / **損益計算書（PL）** / **キャッシュフロー（CF・簡易直接法）**。

### 管理
- **勘定科目・口座**: 科目CRUD（区分タブ）、口座CRUD、口座ごとの入出金プリセット、**クレジットカード返済**（CC設定カードの未払残高表示＋「クレカ返済を生成」）、**自動分類ルール**。
- **タグ・配分**: タグCRUD、タグ別の配分目標。
- **定期取引**: 家賃・給与等の定期仕訳テンプレ＋自動生成。
- **設定**: 表示する画面の選択、テーマ、予算、アカウント削除。
- **操作ガイド / はじめかた**: オンボーディングをいつでも再表示。

## 6. クレジットカードのサイクル仕様（`utils/creditCard.js` に一元化）

- **締めサイクル**: `[前回締めの翌日 〜 今回締め日]`。**月末締め対応**（締め31日→当月末日に丸める `clampDay`）。日付はローカル整形でJSTズレを回避。
- **利用額**: 期間内のカード貸方増（cr−dr）。**引落仕訳（カード借方＋資産貸方）は利用額から除外**。
- **引落予定日**: 締め月 + `ccDelay` ヶ月の `ccDay`（月末は丸め）。
- **状態**: `open`(締め前) / `unsettled`(締め済み未引落) / `settled`(引落済) / `none`(利用なし)。
- **返済仕訳の自動起票（generateCC）**: 上記サイクルに準拠し、**引落日が到来済み（当月＋遡り）の未引落サイクル**について `借方クレカ / 貸方引落口座 = サイクル利用額` を起票。生成済みは重複しない。クレジット画面の表示と完全一致。

## 7. ポイント利用（仕訳入力）

- 摘要欄の下の「🏷 ポイント利用 [金額]」に使ったポイント額を入力。
- **明細は使用額（定価）のまま入力**し、記帳時に**ポイント額を出金（最大額の貸方）から差し引き、同額を「雑収入」へ振替**。**合計（使用額）は不変**。
- 例: 食費3,000 / カード3,000 + ポイント500 → `借方 食費3,000 ／ 貸方 カード2,500・雑収入500`。摘要に「（ポイント利用）」を付与。
- 計上先は収益科目「雑収入」を自動選択。編集時は雑収入行を検出して入力欄へ復元（往復安定）。

---

## 8. 入出力

- **CSV取込**: 列=`日付,借方科目,借方金額,貸方科目,貸方金額,摘要`。1行目ヘッダ有無を選択。科目名→科目ID解決、未解決は行ごとにプルダウンで上書き、重複検知（初期スキップ）、自動分類ルール適用、「選択をリセット」。広いモーダルで操作。**取込中は実行ボタンを非活性**（多件数時の二重取込防止）。
- **エクスポート**: 仕訳帳・BS・PL・CF で **CSV（UTF-8 BOM・Excel文字化け対策）** と **PDF（html2canvas→jsPDF・画像化・印刷ダイアログなしで即DL）**。

## 9. 期間指定（`Dashboard/PeriodBar` 共通）

- チップ: **今月 / 先月 / 先々月 / 今年 / 全期間 / 期間指定**。上部に「📅 YYYY年M月 を表示中」を常時表示。
- 範囲計算は `getPeriodRange`（ローカル日付整形でJSTオフバイワンを是正済み）。
- 利用画面: ダッシュボード / 仕訳入力 / 仕訳帳 / BS / PL / CF / クレジット（クレジットのみ引落日基準）。

## 10. 広告・課金（ティア別）

- Google AdSense のインライン広告。`AD_CONFIG`：ゲスト=多め（サイドバー/ダッシュボード/仕訳帳/遷移3回ごと）、Free=同配置で頻度低（遷移6回ごと）、Pro/Family=なし。
- 広告env未設定時は非表示、広告ブロック時は枠を畳む。全画面インタースティシャルは不使用。

## 11. 外部連携の方針

- **家計データそのものは外部送信しない**。OCR・銀行API・プッシュ通知等は使わない。
- 例外（判断済み）: Google ログイン（認証のみ）／ Google AdSense（家計データは渡さない）。
- AI仕分けは**同意チェックを前提**（下記・未実装）。
