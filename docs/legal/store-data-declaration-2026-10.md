App Store の「Appのプライバシー」と Google Play の「データ セーフティ」を、**今のコードと、2026-10-21 に公開するプライバシーポリシー**に合わせるための差分。
**ストア側は変更していない（見直しのみ）。** 反映は別途許可を取って行う。

## 実装・ポリシーとの食い違い

| 項目 | 実装の根拠 | 今の申告 | 差 |
|---|---|---|---|
| ログイン後の問い合わせ（本文・返信。アカウントに紐づく） | `app/inquiry.jsx`（初回リリースから出荷済み） | なし | **漏れ（出荷済みの機能）** |
| ご意見・退会理由（匿名。本文は残る） | `app/settings/delete-account.jsx` ほか。退会理由は backend 側で保存に変わる（`54946b9`・未デプロイ） | なし | **漏れ** |
| 広告 SDK（AdMob）の収集物のうち、IP アドレス（おおよその位置）・広告の操作・診断情報 | Google の開示ページ（下記） | iOS: デバイスID・広告データのみ／Play: 診断情報・デバイスIDのみ | **不足** |
| アプリの計測（出来事の名前だけ。CloudFront のログに IP が残り 90 日で消える） | `src/track.js`（**未コミット・未配信**） | なし | 配信前に追加が必要 |

Google の開示ページ（確認した内容）:
- Google Mobile Ads SDK（Android）: IP アドレス（おおよその位置の推定）／ユーザーのプロダクト操作／診断情報／デバイスとアカウントの識別子（広告 ID は任意）。目的は広告・分析・不正防止。収集され共有される。
- Google Mobile Ads SDK（iOS）: IP アドレス／クラッシュログ／パフォーマンスデータ／デバイスID／広告データ／その他のプロダクト操作。
- ML Kit（全機能共通）: 端末情報・アプリ情報・インストールごとの識別子・性能指標・入出力の大きさ・イベント種別・エラーコード。目的は診断と利用分析。第三者へは渡さない。

## 提案: App Store（Appのプライバシー）

「トラッキング」は引き続き**いいえ**（非パーソナライズ広告のみ・ATT なし）。

| データ種別 | 用途 | ユーザーに紐づく | 状態 |
|---|---|---|---|
| 連絡先情報 → メールアドレス | アプリの機能 | はい | 変更なし |
| 財務情報 → その他の財務情報 | アプリの機能 | はい | 変更なし |
| ユーザコンテンツ → カスタマーサポート | アプリの機能 | はい | **追加**（ログイン後の問い合わせ。退会後は紐づけを外して残す） |
| ユーザコンテンツ → その他のユーザコンテンツ | 分析 | いいえ | **追加**（匿名のご意見・退会理由）。用途を「分析」にしたのは判断（サービスの改善のため） |
| 識別子 → デバイスID | サードパーティ広告 | いいえ | 変更なし |
| 使用状況データ → 広告データ | サードパーティ広告 | いいえ | 変更なし |
| 使用状況データ → プロダクトの操作 | サードパーティ広告・分析 | いいえ | **追加**（AdMob の操作＋自前の計測。計測は配信前に必要） |
| 使用状況データ → その他の使用状況データ | 分析 | はい | **追加**（最終利用日） |
| 診断 → クラッシュデータ・パフォーマンスデータ | サードパーティ広告・分析 | いいえ | **追加**（AdMob SDK） |
| 位置情報 → おおよその位置情報 | サードパーティ広告・分析 | いいえ | **追加**（AdMob SDK が IP から推定） |

## 提案: Google Play（データ セーフティ）

| データ種別 | 収集 | 共有 | 目的 | 状態 |
|---|---|---|---|---|
| 個人情報 → メールアドレス | はい | いいえ | アプリの機能・アカウント管理 | 変更なし |
| 財務情報 → その他の財務情報 | はい | いいえ | アプリの機能 | 変更なし |
| メッセージ → その他のアプリ内メッセージ | はい | いいえ | アプリの機能 | **追加**（問い合わせ・ご意見・退会理由） |
| アプリのアクティビティ → アプリのインタラクション | はい | はい（広告 SDK） | 広告・分析・不正防止 | **追加**（AdMob の操作・自前の計測・最終利用日） |
| 位置情報 → おおよその位置情報 | はい | はい（広告 SDK） | 広告・分析・不正防止 | **追加**（IP から推定） |
| アプリの情報とパフォーマンス → 診断情報 | はい | はい | 広告・分析・不正防止 | 既存。**目的・共有の内訳を確認** |
| デバイスまたはその他の ID | はい | はい | 広告・分析・不正防止 | 既存。**ML Kit のインストール識別子を含むか確認** |

- 転送時の暗号化: はい。データ削除のリクエスト: アプリ内（設定 → アカウントと同期 → アカウントを削除）。
- 広告 ID の収集は任意の扱い（広告 ID を止めるとデータ種別が減るが、今の設定のまま申告する）。

## 反映のタイミング

- 出荷済みの機能の漏れ（問い合わせ・ご意見・最終利用日・AdMob の内訳）は**今すぐ直す**。
- 自前の計測（`track.js`）の分は、**計測を含むビルドを出す前**に入れる。先に申告しても害はない。
- Apple の「Appのプライバシー」は、新しいバージョンの審査提出前でも変更でき、変更は次の審査で確認される。
