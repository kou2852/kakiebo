# app.kurofukubo.com — アプリ本体
# サービス紹介・ガイドは https://kurofukubo.com/ 側にある。ここはアプリだけを置く。
#
# これまで robots.txt が存在せず、SPA のフォールバックで index.html（HTML）が
# 返っていた。クローラーからは「robots.txt が無い＝全許可」と解釈される状態で、
# 何も制御できていなかった。

User-agent: *
Allow: /

# 自前の計測ビーコン。コンテンツではないうえ、クロールされると実際のイベントとして
# アクセスログに記録され、起動回数や記帳回数の集計が狂う。
Disallow: /_e/

# 検索から来た人の入口は https://app.kurofukubo.com/?guest（ゲストで直接開く）。
# LP の CTA から張られており、素の URL より先にインデックスされている。
#
# /assets/ は意図的に許可したままにする。ここを塞ぐと JS/CSS を取得できず、
# SPA を描画できないため、トップページの内容が正しく評価されなくなる。
#
# sitemap は置いていない。アプリは実質1ページで、LP 側の sitemap.xml にも
# アプリの URL は含まれていない（LP の CTA リンク経由で発見されている）。
